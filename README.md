#Advanced Port Scanner (Python)

A multithreaded TCP port scanner with basic banner grabbing, built in Python.  
Scans any IP or hostname in a specified port range.

#Features
- Fast multithreaded scanning
- Banner grabbing (if available)
- Clean terminal output
- CLI interface with argument parsing

# Usage

```bash
python Advanced_port_scanner.py <target> -p <start-end>

```
# Note

- "target" : can be either an IP or a Domain name 
- "start-end" : is the port range for example -p 1-1000
